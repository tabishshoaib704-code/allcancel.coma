# Browser Games

Open the files in any browser to play — no install or build step.

## Ludo (`index.html`)

Classic Ludo for 2–4 players. Each colour can be a human, a computer, or switched off.

- Roll a 6 to bring a token out of base.
- Land on an opponent to send it back to base (not on starred or start squares).
- A 6, a capture, or getting a token home earns another roll. Three 6s in a row loses the turn.
- First player to get all four tokens home wins.

## Brick Breaker (`brick-breaker.html`)

- Move: mouse, touch, or ← → / A D
- Launch the ball: click, tap, or Space
- Pause: P
